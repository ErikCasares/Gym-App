Instalación

  1. Generar APK/AAB con EAS Build (ver instrucciones abajo).
  2. Colocar el archivo resultante en /web/landing/downloads/ y renombrar a app.apk (o actualizar el enlace).
  3. Servir la carpeta /web/landing con cualquier servidor estático.
# build (ejemplo con EAS)
npm install -g eas-cli
eas login
eas build -p android --profile preview
# descargar APK/AAB desde EAS y copiar a web/landing/downloads/app.apk
